
# Aplikasi Pembelian Tiket Kolam Renang

Aplikasi sederhana menggunakan PHP murni tanpa HTML,
CSS, dan database.

## Fitur
- Input nama pembeli
- Memilih jumlah tiket anak-anak
- Memilih jumlah tiket dewasa
- Menghitung total pembayaran
- Menampilkan struk pembelian
- Validasi data pembelian

## Harga Tiket
- Anak-anak: Rp15.000
- Dewasa: Rp25.000

## Cara Menjalankan
1. Instal PHP.
2. Buka terminal di folder proyek.
3. Jalankan perintah:

   php index.php

## Teknologi
- PHP
